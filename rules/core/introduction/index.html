About This Book

This core rulebook holds the complete, setting-neutral rules of the 2d12 System: the engine, six optional modules, and generic Descriptors, Playbooks and Focuses that work in any genre.

When a rule here mentions another chapter, it uses that chapter’s name and section number. For example, Core Rules §4.1 means Chapter II, section 4.1. A bare reference such as §6 points to a section in the same chapter. Setting books use the same chapter names when they refer back to this book.

Notation

  • ★ Major. An ability that costs 1 extra Refresh whenever you take it (Core Rules §3.6, Generic Playbooks §1.2).

  • ◆ Capstone. A playbook’s final ability, unlocked by advancement. Take it as an Advance; it costs no Refresh (Core Rules §12.2).

  • ◈ Weird. A Focus that assumes the supernatural, strange technology or other weird elements. Each setting decides which ◈ Focuses it allows and how its world reacts to them.

  • Tags are written in italics, such as scarred knuckles. Personal statuses use a space and a signed value: inspired +2 reads “inspired plus two”; wounded −2 reads “wounded minus two”. Use a true minus sign (−), not a hyphen. The sign stays attached to the number. This notation doesn’t override a status’s specific rules. Situational Conditions add an unsigned rating, such as smoke cover 2. Truths carry no number.

  • Difficulty is written by name and target, such as Standard 15 or Hard 18.

Settings
The 2d12 System has no setting of its own. A setting book adds Campaign Truths, a skill list, its own Descriptors, Playbooks and Focuses, and special rules for its creatures and dangers. Where a setting rule and a general rule conflict, the setting rule wins.

Terminology

House name

What it is

Woe

The GM’s pool: complications and escalation

Weal

The party’s shared pool of surplus Power

Tychē / Tychē Points

Each PC’s narrative currency: invoke tags, accept compels; set by Refresh

Sōma

Pool: strength, endurance, toughness, vitality. Resists wounds, poison, exhaustion, cold

Mētis

Pool: speed, precision, stealth, reflexes. Resists traps, falls, being caught or grabbed

Psychē

Pool: mind, intellect, perception, memory, cunning. Resists confusion, illusion, deception, madness from knowledge

Pneuma

Pool: spirit, will, presence, faith, the supernatural. Resists fear, despair, possession, corruption, social pressure

Mage, psychic, hacker; anchor Arcana or Tech

  • Pool shorthand. Playbook stat blocks list base pools as Sōm / Mēt / Psy / Pne (Sōma / Mētis / Psychē / Pneuma).

  • Scars take the name of the pool most tied to the condition that caused them: a Pneuma Scar, a Psychē Scar (Core Rules §6.3).
